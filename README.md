# 🎵 AURA Music Player

AURA Music Player is a modern and responsive web-based music player developed using HTML, CSS, and JavaScript.

This project was created as part of the **CodeAlpha Frontend Development Internship**.

## ✨ Features

- ▶️ Play and pause music
- ⏮️ Previous song
- ⏭️ Next song
- 🎵 Playlist support
- 📊 Music progress bar
- 🔊 Volume control
- ⏱️ Current time and duration
- 🖼️ Album artwork
- 🔄 Automatic next song
- ✨ Smooth animations
- 🎨 Modern user interface
- 📱 Fully responsive design
- 🖱️ Interactive buttons and controls

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- HTML5 Audio API

## 🎧 Music Player Controls

| Control | Function |
|---|---|
| ▶️ Play | Play the current song |
| ⏸️ Pause | Pause the current song |
| ⏮️ Previous | Play the previous song |
| ⏭️ Next | Play the next song |
| 🔊 Volume | Control music volume |
| 📊 Progress Bar | Control playback position |
